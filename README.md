## 使用技術・起動

HTML / CSS / Vanilla JavaScript。外部ライブラリ・外部フォント・API・データベースは使用していません。画像はWebPで同梱しています。

`index.html`をブラウザで開くだけで確認できます。GitHub Pages等には `index.html`、`styles.css`、`script.js`、`assets/` を同じ階層に配置してください。ビルドは必須ではありません。Node.jsがある環境では `npm run build` で `dist/` に公開用ファイルをまとめられます。依存パッケージのインストールは不要です。

## 写真の扱い

参考サイトに掲載された写真を取得しWebPに変換しています。架空の施工画像や別会社のストック写真は使用していません。出典URLは `assets/sources.json` に保存しました。元の写真に工事名等の文字が含まれているものがありますが、サイト本文では未確認の工事名・施工場所・施工年を補っていません。メイン写真と会社紹介写真はCSSで表示範囲を調整しており、元画像は保持しています。

実サイト化の際は、和田工業に画像利用・掲載内容を確認し、必要に応じて高解像度写真へ差し替えてください。差し替えは同じファイル名で保存すると容易です。

## フォームとサンプル表示

- フォームは実送信しません。送信先URL・通信処理・ブラウザ保存はありません。
- ボタンは `type="button"` とし、Enter等のsubmitイベントもキャンセルします。入力欄には送信用のname属性を付けていません。
- ボタンを押すと「こちらはリニューアル提案用サンプルのため、現在フォーム送信はできません。」と表示します。
- 電話・メールリンクは参考サイトの実連絡先につながります。これらはサンプルフォームとは別です。
- フッターに指定の提案用サンプル表記を掲載しています。
- 公式サイトとの混同を避けるため、提案段階では `noindex, nofollow` にしています。title / description / OGPは設定済みです。
